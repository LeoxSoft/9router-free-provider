9ROUTER SETUP

Add Dahl Global

  1. Open 9Router.
  2. Open Providers.
  3. Select Add Provider.
  4. Select OpenAI Compatible.
  5. Set the provider name to Dahl Global.
  6. Set the Base URL to https://inference.dahl.global/v1.
  7. Set the prefix to 1.
  8. Add each generated API key as a separate connection.
  9. Name the connections sequentially as dahl1, dahl2, dahl3 and so on.
  10. Keep every connection at Priority 1.
  11. Save the provider and test the connections.

IMPORT

Import the Prepared Backup

  1. Open 9Router.
  2. Open the backup or restore section.
  3. Select the option to import a backup.
  4. Choose the prepared JSON backup file.
  5. Complete the import process.
  6. Open Providers and verify Dahl Global.
  7. Verify the generated dahl1, dahl2, dahl3 and additional connections.
  8. Verify the Dahl Global models.
  9. If enabled, verify the Free 9Router combo.
