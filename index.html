Add to 9Router

  1. Open 9Router.
  2. Open Providers.
  3. Select Add Provider.
  4. Choose OpenAI Compatible.
  5. Set the provider name to Dahl Global.
  6. Set the Base URL to https://inference.dahl.global/v1.
  7. Set the API prefix to 1.
  8. Add each generated API key as a separate connection.
  9. Keep every connection at Priority 1 so they remain at the same priority level.
  10. Save the provider and test the connections.
